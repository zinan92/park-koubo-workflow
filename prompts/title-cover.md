# 标题与封面 · v2

制作前必须读 `references/douyin-cover.md`、默认封面 preset 并实际查看其横竖参考图；不能只记住“橙黑配色”。

先读完整转写、视频主题和用户这次的标题要求。给 3–5 个简短、具体、有反差的候选，每条写出正文中的兑现依据。冲突来自真实观点，不凭空承诺收入、效果或替作者升级判断。用户明确选定标题后逐字使用，不再自行改字；发布准备中更换标题默认同步两张封面文案；用户明确只改平台标题才保留封面并记录 cover_title_override。纯候选讨论不触发上传。

默认交付横版 4:3、竖版 3:4 两张独立构图的封面；用户指定其他比例时按此次要求记录。不要简单裁切横版得到竖版，需分别检查标题与人脸的可见区域。

人物来源默认是本期视频的清晰截图：先列出源视频路径/哈希、截图时间点和截图哈希，再制作。上一期封面只作为排版、字体、配色参考；不得把上一期的人脸/衣服/姿态作为本期素材。若用户明确另选人物素材，必须记录这次的来源覆盖，不能伪称来自本期视频。

制作/编辑图片按可用 imagegen skill 执行，先查看本期截图和参考图，并在提示词中分别注明 sole person source / style reference。避免遮脸、错误字、额外文案和不可辨识的小字。

逐张看生成结果：人物是否对应本期截图、标题是否逐字一致、表情/服装是否错误替换、比例是否正确、缩略图是否可读。图片文件存在不等于这些检查通过。

当前标题、封面、视频版本统一写入 release.json。用户已要求更新平台时，修改本地完成后继续更新草稿并读回标题、封面与视频；不要只交本地图片就结束任务。用户明确只要本地修改时则不动平台。
